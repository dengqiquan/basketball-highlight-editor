# 按标签均衡合并导出

## 目标

在现有导出页新增“按标签均衡合并”方式。用户选择参与的标签，再指定一个基准标签。基准标签中当前可导出的片段数为 N；每个参与标签随机取 `min(该标签可导出片段数, N)` 段，合成一个 MP4。被排除的片段不计数、不参与抽样。

## 交互

- 沿用“导出范围”的多选标签；新方式下必须选择至少一个有可导出片段的标签，且基准标签必须属于所选范围。
- 新方式下展示基准标签选择器、N 和各标签预计取用数量。未标记片段不作为基准；若选中“未标记”，它也按 N 抽样。
- 导出按钮显示本次预计片段总数，保存位置选择一个 MP4 文件。
- 其他三种输出方式保持现有行为。

## 数据流

- 前端把新模式 `merge_balanced` 和基准标签 ID 发给 Engine。Engine 按已有导出范围生成候选快照，再计算 N 并在每个标签内随机抽样；结果作为该导出任务的固定候选快照。
- 编码复用现有 `merge` 路径，片段按已有时间顺序合并。随机抽样只发生一次，编码期间的审核修改不影响任务。
- 任务检查点保存抽中的片段 ID 和完整快照；重试沿用同一批片段，不重新随机选择。缺失原视频或片段时明确报错，不静默替换。

## 验证

- Engine 测试覆盖：超过 N 随机取 N、不足 N 全取、排除片段、未标记片段、基准标签无可用片段、重试保留抽样结果。
- Flutter 测试覆盖：新模式下的基准标签选择、预计数量和请求参数。
- 运行相关测试、静态分析，并通过本地 dev 桌面程序验证启动和导出配置。
